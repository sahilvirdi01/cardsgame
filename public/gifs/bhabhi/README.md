# Bhabhi (loser) GIFs

Drop the reaction GIFs shown on the **game-over / Bhabhi** screen here, e.g.
`bhabhi.gif`, `bhabhi-cry.gif`, `so-sad.gif`. Any `.gif`, `.webp`, `.apng`,
`.png` or `.jpg` in this folder is picked up automatically (the server scans it
on every page load).

These are kept separate from the **Thulla** GIFs in `public/gifs/`. If this
folder is empty, the game falls back to the Thulla pool.

To give a file a nicer label, add an optional `manifest.json` next to it:

```json
[
  { "file": "bhabhi.gif", "label": "Bhabhi!" }
]
```
